## 使用方法

1. 复制上面的官方地址，粘贴到浏览器地址栏打开。
2. 苹果手机请用自带的 **Safari** 浏览器，安卓手机请用 **谷歌浏览器（Chrome）** 或 **火狐浏览器（Firefox）**。
3. 进入后先注册登录，再开始使用。

## 注意事项

- 请认准本页列出的官方地址，其他来源的链接可能是仿冒站点。
- 不要用微信、QQ 内置浏览器打开，容易被拦截或打不开。
- 一定要注册账号，不要以游客身份使用，否则换手机或清缓存后记录无法找回。
- 建议绑定手机号，方便找回账号。
- 如果地址打不开，请回到本仓库查看最新地址，建议收藏本页。
